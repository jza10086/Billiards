# 夜幕球房 · Billiards 3D

独立的 Godot 4.7.2 美式八球小游戏。真实 3D 球桌、球体、球杆与球房场景，本地两人轮流操作。打开 `project.godot`，按 **F5** 开始。

## 操作

- 鼠标移动：白球指向鼠标位置，细线显示第一段瞄准方向。
- 按住鼠标左键或空格：蓄力；松开击球。蓄满后保持最大力度，不循环。
- 右键拖动：绕球桌旋转视角；滚轮缩放。
- V：俯视 / 斜视切换。
- 自由球：移动鼠标选择位置，左键确认放置。不可放在其他球上、袋口或台外。
- R /「重新开局」：确认后重新摆球。Esc 打开玩法说明；在弹窗中 Esc 关闭。
- 球运动时不能再次击球；切换视角、打开弹窗或窗口失焦会取消当前蓄力。
- 在 HUD 上松开鼠标会取消蓄力，不会误击球。

## 本地双人简化八球

1. 玩家 1 开球。开球至少进一颗目标球，或让 4 颗不同目标球碰库；开球不分组。开球黑 8 重新放回球台，不直接判胜。
2. 开放球局时，第一次合法进球确定全色（1–7）或花色（9–15）。同一杆两组都入袋时，以第一颗入袋球的组别为准。
3. 必须先碰到本组球；清完本组后才能先碰黑 8。开放球局不能先碰黑 8。
4. 碰球后必须有球入袋或碰库。合法打入本组球继续，否则换人。
5. 白球入袋、未碰到球、先碰错球或未满足碰库要求均为犯规。对方获得整台自由球；犯规入袋的目标球不取回。
6. **击球开始时已清完本组**，再合法打进黑 8 获胜。提前打进黑 8、最后一颗本组球与黑 8 同杆入袋、黑 8 入袋同时犯规均判负。

这是明确简化的休闲规则，**不是完整 WPA / 中式八球裁判实现**：不要求叫袋、不含安全球声明、争议判罚或非法开球重摆选项。没有 AI、联网或斯诺克规则。

## 物理与画面

画面使用 Godot 的 3D Mesh、灯光、阴影、材质和透视相机。球的运动使用独立的 **XZ 平面定步长求解器**（480 Hz 子步），模拟等质量球碰撞、库边反弹、滚动减速和六袋捕获，再同步到 3D 球体。球体滚动与落袋动画由真实位置 / 速度驱动。

这不是完整刚体桌球模拟器：不含旋转 / 塞、跳球、弧线球、球杆抬升、桌面不平或完整 3D 袋角动力学。袋口采用圆形捕获区域与库边开口。瞄准线只预测首次接触或库边，不显示完整反射路线，也不保证进球。

## 项目结构

- `scenes/main.tscn`：直接可运行场景。
- `scripts/main.gd`：操作、相机、界面、球杆、3D / 物理同步。
- `scripts/pool_physics.gd`：独立、可测试的平面物理。
- `scripts/pool_rules.gd`：双人八球回合与胜负。
- `scripts/table_art.gd`：原创球桌、六袋、球房和球体材质。
- `assets/`：编号球贴图、木材贴图、音效、字体和许可证。
- `ART_SOURCES.md`：素材来源与许可；原创及第三方部分分别列出。
- `tests/`：规则 / 物理 / 独立审查测试、原生渲染截图脚本。

## 测试

将 `godot` 替换为本机 Godot 可执行文件路径：

```sh
godot --headless --path . --script tests/test_pool_core.gd
godot --headless --path . --script tests/test_independent_review.gd
```

测试应输出 PASS 且退出码为 0。截图脚本必须使用真实图形渲染器，不能以 headless 空图替代。开发检查不会对比文件哈希。

## 运行环境

推荐 Godot 4.7.2，GL Compatibility 渲染器。默认 1280×800 窗口，最低 960×640；推荐键鼠。该项目不是 Windows EXE，源码包不包含 Godot 编辑器或导出模板。可在 Godot 安装官方导出模板后自行导出 Windows。
