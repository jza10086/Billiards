# 3d桌球

2–8 人九球分桌赛；优先两人桌，奇数组最后三人桌，每桌一名胜者，胜负分组继续决出名次。

开局按本局种子打乱座次。1–9 菱形摆球，先碰台面最小号球，合法进任何目标球可继续，合法打进 9 号球立即赢桌。犯规：未碰球/先碰错号/白球入袋/无进球且碰撞后无球碰库；开球还要求进目标球或至少四颗目标球碰库。犯规下家全台自由球；犯规进 9 重摆 9。三人桌顺次轮转，两位未赢者进入败者组继续比较。先前胜者组始终排在相应败者组之前；不是随机轮盘淘汰，也不是完整 WPA 规则（无推杆、跳球、连续三犯判负）。默认每杆 30 秒，包括摆白球，球运动时停止倒计时；超时犯规。赛事默认 600 秒保护时限，超时或有人断线取消，不按剩余球数猜胜负。主机独占物理，客户端选择力度、瞄准方向和击球点；可切换观看其他桌。

物理采用 240 Hz 固定步长及球/库边的连续碰撞检测，区分滑动摩擦和滚动阻力。高杆可跟进，低杆可拉回；左右塞参与球间摩擦和碰库反弹，强力碰库的法向恢复系数较低。袋口具有实体袋角，球心越过袋喉才收球；可见胶边和碰撞使用同一套线段。球体姿态随角速度转动，主机以 30 Hz 发送状态。该模型保持球在台面内运动，未模拟跳球、扎杆弧线和偏杆偏移，不宣称复现参考游戏的内部参数。

操作：移动鼠标瞄准，力度滑条控制出杆速度，按“出杆”击球。点击或拖动侧栏白球图选择击球点：上方高杆、下方低杆、左右加塞；“恢复中杆”回到中心。击球点限制在球半径的 80% 内。自由球时先点击台面摆白球。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

当前定向验证脚本位于主项目忽略目录 `tmp/test/billiards_physics/`，覆盖旋转与摩擦、碰撞、进袋、开球稳定性、输入边界及真实大厅两端状态同步。旧 `tests/` 已归档，不作为当前验收依据。真实键鼠杆法手感、多人体验及外网仍需人工检查。
