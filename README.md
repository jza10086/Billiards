# 夜幕球房

2–8 人九球分桌赛；优先两人桌，奇数组最后三人桌，每桌一名胜者，胜负分组继续决出名次。

开局按本局种子打乱座次。1–9 菱形摆球，先碰台面最小号球，合法进任何目标球可继续，合法打进 9 号球立即赢桌。犯规：未碰球/先碰错号/白球入袋/无进球且碰撞后无球碰库；开球还要求进目标球或至少四颗目标球碰库。犯规下家全台自由球；犯规进 9 重摆 9。三人桌顺次轮转，两位未赢者进入败者组继续比较。先前胜者组始终排在相应败者组之前；不是随机轮盘淘汰，也不是完整 WPA 规则（无推杆、跳球、旋转、连续三犯判负）。默认每杆 30 秒，包括摆白球，球运动时停止倒计时；超时犯规。赛事默认 600 秒保护时限，超时或有人断线取消，不按剩余球数猜胜负。主机独占物理，客户端选择力度和瞄准方向；可切换观看其他桌。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

自动化：tests/original_arcade_rules_test.gd（规则、清单、人数）和 tests/original_arcade_network_test.gd（正式大厅、轮换、4/5 个 ENet 端、UI 回调和结算）。真实键鼠、多窗口手感及外网仍需人工检查。
